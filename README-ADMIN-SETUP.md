# أهل العود — لوحة الإدارة (مسودة تنفيذ)

## الحالة
هذه التغييرات موجودة على فرع منفصل ولا تُنشر تلقائيًا على الموقع الرسمي. لوحة الإدارة تحتاج إعداد Supabase قبل أن تعمل.

## إعداد Supabase
1. أنشئ/استخدم مشروع Supabase الخاص بأهل العود.
2. نفّذ ملف `supabase-schema.sql` في SQL Editor بعد مراجعته.
3. أنشئ حساب المدير من Supabase Auth بنفسك، مع تعطيل التسجيل العام.
4. انسخ UUID الحقيقي للمستخدم وأضفه إلى `public.store_admins` باستخدام الاستعلام الموجود آخر ملف SQL.
5. ضع Project URL وanon/publishable key فقط في `config.js`. ممنوع وضع service_role key في الموقع.
6. فعّل سياسات المصادقة المناسبة واضبط رابط استعادة كلمة المرور في Supabase.

## المسارات
- المتجر: `/`
- لوحة الإدارة غير المرتبطة بالقائمة العامة: `/admin.html`

## حدود النسخة الحالية
- إدارة المنتج (الاسم والوصف والسعر والحجم والتصنيف والصورة وحالة المسودة/النشر) مدعومة بعد إعداد Supabase.
- ألوان وخطوط الواجهة مثبتة حاليًا في CSS؛ محرر المظهر الديناميكي غير منفّذ بعد.
- لا تُعلن أن المتجر جاهز للإنتاج قبل ضبط إعدادات Supabase واختبار الدخول والرفع وRLS على مشروع حقيقي.
