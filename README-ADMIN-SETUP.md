# أهل العود — لوحة الإدارة

## الحالة الحالية
- مشروع Supabase الخاص بأهل العود مضبوط في `config.js` باستخدام رابط المشروع والمفتاح العام publishable فقط.
- جداول `products` و`store_admins` وسياسات RLS ومخزن الصور `product-images` أُنشئت في مشروع Supabase الحالي.
- تمت إضافة حساب `sahlanalkojok@gmail.com` إلى `public.store_admins` والتحقق من وجود سجل المدير.
- طلب الدمج ينشر ملفات المتجر ولوحة الإدارة إلى الفرع الرئيسي؛ يلزم اختبار الموقع بعد النشر.

## إعداد وتسجيل الدخول
1. افتح `/admin.html` بعد نشر التعديلات.
2. سجّل الدخول بالبريد `sahlanalkojok@gmail.com` وكلمة مرور حساب Supabase Auth.
3. إذا لم تعرف كلمة المرور، استخدم خيار «استعادة كلمة المرور» في صفحة الإدارة.
4. لا تضف مفتاح `service_role` أو أي مفتاح سري إلى ملفات الواجهة؛ المفتاح الموجود في `config.js` مخصص للاستخدام العام.

## المسارات
- المتجر: `/`
- لوحة الإدارة غير المعروضة في قائمة المتجر: `/admin.html`

## حدود النسخة الحالية
- لوحة الإدارة تشمل إضافة وتعديل وحذف المنتجات، ورفع صورها، وحالة المسودة/النشر.
- الألوان والخطوط مثبتة في CSS؛ محرر مظهر ديناميكي غير منفّذ.
- لا تعتبر كل تدفقات الاستخدام مختبرة بعد: يجب تجربة تسجيل الدخول، وحفظ منتج، ورفع صورة، وظهور المنتج المنشور على الموقع بعد النشر.
